# GPT Image 2 Room Asset Prompt

Use this prompt to generate three purchasable Spritebury room backgrounds as separate production assets.

```text
Create three separate isometric pixel-art room images for Spritebury, a cozy early-2000s virtual city life browser game.

Output exactly 3 separate PNG images:
1. Cozy living room
2. Cozy bedroom
3. Cozy bathroom

Shared style requirements:
- isometric pixel art, crisp pixel clusters, no blur, no painterly brushwork
- nostalgic early/mid-2000s virtual world style, cute and polished
- same camera angle, same room footprint, same scale across all three rooms
- each room should feel purchasable as a player home room background
- no people, no pets, no UI, no labels, no logos, no text
- no watermark, no poster border, no mockup frame
- clean readable furniture silhouettes with enough open floor space for player avatars and placed furniture
- warm cheerful palette that matches Spritebury's opening screen: sky blues, honey wood, soft greens, pink accents, cream walls
- black or dark brown pixel outlines, but not harsh
- 3/4 isometric walls and floor visible, like a virtual dollhouse room
- floor grid perspective should be subtle and consistent enough for future furniture placement
- lighting from upper left, soft shadows under furniture
- high-resolution PNG while preserving pixel-art edges

Room details:

Living room:
- small sofa, coffee table, rug, bookshelf, potted plant, wall art, window, cozy lamp
- inviting but not cluttered
- leave the center floor area mostly open

Bedroom:
- single bed, bedside table, dresser, mirror, small rug, window, soft lamp
- cozy player apartment feel
- leave room for avatar standing space near the front center

Bathroom:
- bathtub or shower, sink, mirror, towel rack, small cabinet, tile floor, bath mat
- clean and cute, not sterile
- leave enough open floor area for avatar and future decorative items

Composition:
- each room should be a full room background, not a floating object icon
- consistent room footprint and camera angle across all images
- transparent background outside the room shape if possible; otherwise use a clean flat transparent-compatible backdrop
- make the images suitable for direct use in a browser game as room backgrounds
```

Optional stricter output note if the model supports exact sizing:

```text
Use a 1024x768 canvas for each room. Keep the room footprint centered and do not crop walls, floor, or furniture.
```
